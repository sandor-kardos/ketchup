# Ketchup

Import messy ChatGPT / Claude / Gemini chat exports, group them by topic and get short restart briefs. Everything is processed locally in the browser (no upload, no account).

- Single file app: `index.html` (published as a claude.ai artifact; the Community tab needs the artifact `db` capability)
- `og-image.png`: social preview image
- Live: https://chat.sandorkardos.com
